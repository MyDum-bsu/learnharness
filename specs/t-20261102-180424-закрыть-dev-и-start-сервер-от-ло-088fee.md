# Spec

## Intent

Убрать сетевую доступность dev/start-сервера по умолчанию: `package.json` запускает Next с явным loopback-хостом, документация фиксирует то же требование для standalone-запуска. Никакой рантайм-логики, аутентификации и Electron-кода это не касается.

Текущее состояние (`package.json:15-18`): `"dev": "next dev"`, `"start": "next start"`. Next по умолчанию слушает `0.0.0.0`; `src/server/desktop-access.ts:5-15` при отсутствии desktop-секрета пропускает всё, поэтому телефон в LAN получает UI, `/api/keys` и SSE (`.agent/review-2026-11-02.md` §3.5).

## Given

- `package.json` содержит `scripts.dev: "next dev"` и `scripts.start: "next start"` без флагов хоста.
- `docs/development.md` описывает `npm run dev` / `npm start` как обычные dev-команды и содержит предупреждение про trusted developer-server mode, но нигде не требует loopback-хоста для standalone.
- Установлен Next `^16.4.3`; `next dev` и `next start` принимают `-H, --hostname <host>`.

## When

Рабочий меняет ровно два файла:

1. `package.json`: `scripts.dev` → `next dev -H 127.0.0.1`, `scripts.start` → `next start -H 127.0.0.1`. Остальные скрипты (`build`, `test`, `lint`, `typecheck`, `desktop:dev`, `dev:fresh`, `desktop:dist`) остаются байт в байт прежними.
2. `docs/development.md`: рядом с существующим предупреждением про trusted local/shared developer-server mode добавляется короткая формулировка, что `npm run dev` и `npm start` слушают `127.0.0.1`, а standalone-сервер (`node .next/standalone/server.js`) должен запускаться с `HOSTNAME=127.0.0.1`. Строка `HOSTNAME=127.0.0.1` присутствует в файле дословно. Остальной текст раздела не переписывается.

## Then

- `dod` (см. frontmatter) завершается с кодом 0: скрипт `check.mjs` читает `package.json` и `docs/development.md` от корня репозитория.
- Oracle проверяет: `scripts.dev` начинается с `next dev`, `scripts.start` — с `next start`; в каждой команде есть `-H`/`--hostname` со значением строго `127.0.0.1`; ни в одной нет `0.0.0.0`; в `docs/development.md` есть `HOSTNAME=127.0.0.1`.
- `git diff --name-only` даёт ровно `package.json` и `docs/development.md`.
