# Intent

У application turn (prober / teacher / practice) появляется предохранитель: предел tool calls и предел
wall-clock. По исчерпании — ран останавливается штатным путём, наружу уходит точный blocker, usage хода
пишется как обычно, частичный транскрипт сохраняется. Это fuse, а не лимит: 100 вызовов и 30 минут
не должны срабатывать на нормальном уроке, и owner ruling 2026-09-25 (снятие `maxTurns`) не отменяется.

Контракт, который обязан появиться в `src/agent/turn-fuse.ts` (единственный источник политики, без I/O
и без таймеров):

```ts
export const DEFAULT_MAX_TOOL_CALLS = 100;
export const DEFAULT_MAX_WALL_CLOCK_MS = 30 * 60_000;

export type FuseDimension = "tool_calls" | "wall_clock";
export interface FuseTrip {
  dimension: FuseDimension;
  observed: number;   // clamped на limit
  limit: number;
  blocker: string;    // см. формат ниже
}
export interface TurnFuse {
  observeToolCalls(count?: number): FuseTrip | undefined; // default count = 1
  check(): FuseTrip | undefined;                          // wall-clock
  readonly toolCalls: number;
  readonly tripped: FuseTrip | undefined;
}
export function createTurnFuse(opts?: {
  maxToolCalls?: number;
  maxWallClockMs?: number;
  startedAt?: number;
  now?: () => number;   // инъекция часов для тестов
}): TurnFuse;
```

Формат blocker (стабильный, английский):
`turn fuse tripped: tool_calls=<observed> limit=<limit>`
`turn fuse tripped: wall_clock_ms=<observed> limit=<limit>`

Шов в `src/agent/teacher-agent.ts` (`baseAgentOptions`): fuse создаётся на сборку агента;
`finishTurn` сначала спрашивает существующий вопросный стоп-хук, затем отдаёт fuse число toolCall-элементов
сообщения турна; при trip возвращает `{ action: "end" }` и однократно вызывает
`opts.onFuseTrip(trip)` (новое поле `AgentBuildOptions`). Wall-clock: `setTimeout` на остаток
дедлайна, `unref`, по срабатыванию `check()` → `agent.abort()` + однократный `onFuseTrip`; таймер
снимается на `agent_end`. Никаких исключений из середины рана.

Шов в `src/server/chat-handler.ts` / `src/server/pi/ui-stream.ts`: trip доходит до учащегося как
`{ type: "error", errorText: blocker }` и `rememberTurnFailure(chatId, blocker)`, при этом settlement
идёт штатно (сообщения + usage пишутся). Ничего другого в этих файлах не меняется.

# When

- В `src/agent/turn-fuse.ts` появляется модуль политики из Intent.

  и однократно рапортует trip.

- Запускается `dod`.

# Then

- `createTurnFuse()` с дефолтами: `observeToolCalls()` возвращает `undefined` на вызовах 1..99,
  на 100-м — trip с `dimension: "tool_calls"`, `observed === 100`, `limit === 100`,
  `blocker === "turn fuse tripped: tool_calls=100 limit=100"`.
- 10 000 наблюдений: первый trip приходит ровно на 100-м, дальше `fuse.toolCalls === 100`
  (счётчик замер), blocker не меняется.
- `createTurnFuse({ maxToolCalls: 3 })` срабатывает на 3-м вызове — предел параметризован.
- Wall-clock с инъекцией `now`: за 1 мс до 30 минут — `undefined`; на 30-й минуте — trip
  `turn fuse tripped: wall_clock_ms=1800000 limit=1800000`; повторный `check()` отдаёт тот же объект-по-значению.
- Через настоящий `createTeacherAgent(undefined, { engine: faux, tools: {...}, onUsage, onFuseTrip })`
  с движком, бесконечно зовущим инструмент: `onFuseTrip` вызван ровно один раз, blocker —
  `tool_calls`-вариант с пределом 100, в `agent.state.messages` ровно 100 toolCall-элементов,
  коллектор `onUsage` получил хотя бы одно событие.
- Тот же агент с 40 вызовами и финальным текстом: `onFuseTrip` не вызван ни разу, 40 toolCall-элементов,
  финальный текст на месте, usage собран, висящих таймеров нет.
- `dod` зелёный; negative corpus (fuse, который никогда не срабатывает) роняет oracle.

# Forbidden

- Возвращать `maxTurns` в teaching-агента или вводить низкий «правильный» лимит ходов.
- Менять субагентов, `TOOL_TIMEOUT_MS`, вопросный стоп-хук (`makeQuestionStopper`), admission, 409-гвард,
  liveness, compaction, формат SSE-событий за пределами добавления `{type:"error"}`.
- Новые env-переменные, UI настроек, ретраи fuse, «умное» продление предела.
- Терять сообщения/usage при срабатывании, обрывать ран исключением или падать без blocker'а.
- Стрелять больше одного раза за ход; рапортовать trip, когда вопросный стоп-хук уже закрыл ход.
- Трогать `tests/`, `oracle/`, `specs/`, `package.json`, `tsconfig.json`.
- Считать 10 000 tool calls «нормальным уроком» или подгонять тесты под реализацию.
