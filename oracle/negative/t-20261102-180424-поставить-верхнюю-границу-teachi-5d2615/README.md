# Negative control — turn fuse

Декалойный «предохранитель, который никогда не срабатывает». Проверяет, что oracle действительно
кусается: с этой реализацией teaching-ход по-прежнему может крутить инструменты бесконечно.

## Состав

- `kit.patch` — `git apply` на **чистую базовую** копию дерева (файла `src/agent/turn-fuse.ts`
  там нет). Патч создаёт модуль с полным публичным API, но `observeToolCalls()`/`check()` всегда
  возвращают `undefined`.

## Ожидание

1. Применить `kit.patch` к копии базовой ветки.
2. Запустить `dod` из спеки:
   `node --test oracle/t-20261102-180424-поставить-верхнюю-границу-teachi-5d2615/turn-fuse.test.ts`
3. Тест обязан **упасть**. Ожидаемые точки отказа:
   - `does not trip on tool calls 1..99 and trips exactly on the 100th` — trip не приходит;
   - `freezes at the limit…` — 10k вызовов не останавливаются;
   - `wall clock…` — дедлайн не срабатывает;
   - блок «in a real teacher run» — `onFuseTrip` базовым `createTeacherAgent` не поддерживается,
     ран уходит на 500 tool calls вместо 100.

Если с декаем тест зелёный — oracle не проверяет ничего и должен быть переписан до старта работ.
